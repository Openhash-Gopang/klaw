## M-1 법령 원문 대조 (텍스트 매칭 전용)

```
검출된 직접 인용 조문: 0건
[원문 확인] 0건 / [불일치] 0건 / [출처 없음] 0건
```

- 판결문(최종 블록 포함)은 **어느 법령의 조문 문언(text)도 직접 인용하지 않는다.** 도정법·토지보상법·민법 조문은 모두 조문 번호와 규율 대상만 언급하고("민법 제741조 소정의 부당이득", "도정법상 관리처분계획 인가·고시 규정"), 문언을 그대로 재현한 구절은 없다.
- 특히 A-0-S-2의 `"관리처분계획의 인가·고시로 종전 소유자의 소유권이 사업시행자에게 이전되고…"`, `"수용개시일까지 보상금이 공탁되면 수용 효과가 확정된다."`, `"타인 부동산 무권원 점유·사용의 차임 상당 이익은 부당이득이고…"` 3건은 **따옴표로 묶여 있으나 "확립 법리"(원칙 수준) 요약**이며 조문 문언의 재현이 아니다. 개요 (a)에도 이에 대응하는 조문 문언·법리 서술이 없다. 조문 문언이 아니므로 [원문 확인]/[불일치]/[출처 없음] 판정 대상은 아니나, 개요와의 대조상 "출처 없음"에 준한다 — 다만 판결문 스스로 "원칙 수준"·이후 [미검증]으로 표시하고 있어 616497류 **확정적 조문 창작은 아님**.
- 참고(경계 사례): STEP-0-0-1의 `"원심이 적법하게 확정한 사실에 기속되고(민사소송법 제432조)"`는 조문 내용을 **요약**한 것으로 문언 재현은 아니나, 개요에 없는 조문을 [미검증] 표시 없이 원칙 수준으로 서술한 지점이다. 절차적 인용이고 결론과 무관.

**결론 영향 후보**: 없음 — 조문 문언 환각이 애초에 발생하지 않았다.

## M-1b 미검증 플래그 전파 대조 (공리 J §7-3 / V-7)

```
검출된 미검증 표시: 15건 이상
  (A-0-S 대상 1·2·3·4 [2단계] / A-0-S-2 [1][2][3] / A-2-1 조문번호 / B-2-β 판례번호 /
   B-4 형식-실질 [형식-실질] / B-5-B 독일·프랑스·ECHR / B-7-③-ν 규범 1·2·3)
[미검증 플래그 위반] 0건 / [자기 정정 확인됨] 1건 / [자기 검증 누락] 0건
```

**[자기 정정 확인됨 — §7-3 위반 1건]**

STEP V-공통점검(【점검 1】)이 다음 자기모순을 **스스로 발견**하였다:

- 선행(정정 전 B-4): "관리처분계획의 효력 요건은 **문언상 명확하므로** 실질 해석을 발동하지 않는다" / [형식-실질 비교] "해당 법문의 문언은 명확한가: **예**"
- 후행(B-7-③-ν): "도정법상 관리처분계획 인가·고시 규정 — **[미검증]**"

이것이 617151에서 최초 확인된 전형 패턴(미검증 대상에 대한 확정적 단언)과 동일하다. 최종 판결문 블록에서 실제로 해소되었는지 확인한 결과:

- 최종 B-4는 "**확립된 판례 법리에 비추어** 명확한 기준이 확립되어 있어…"로 재서술하고, `※ 도정법 조문 원문은 개요에 제시되지 않아 [원문 확인: 파라메트릭 기억(미검증)] 상태이므로, 문언 자체의 직접 인용·확정적 인용은 하지 않고…원칙 수준에서 서술한다`를 부기하였다.
- 최종 [형식-실질 비교 분석]은 "법문의 문언 원문 대조: **불가**(개요 미제시, [미검증])", "『문언상 명확하다』는 형식적 판단 **대신**…'효력 요건이 **법리상** 명확하다'고 원칙 수준에서 판단한다"로 명시적으로 종전 표현을 철회하였다.

→ §7-3 위반이 실제로 해소됨. **[자기 정정 확인됨]** (무이행으로 처리하지 않음, §2b-4).

**잔여 관찰(경미·비HIGH)**: 정정문이 "확립된 판례 법리"·"법리상 명확하다"고 단언하는 부분은, B-2-β·A-0-S-2에서 판례 법리 자체를 "(원칙 수준, [미검증])"으로 표시한 것과 어느 정도 긴장 관계에 있다. 다만 K-Law 체계상 "확립 법리 = 원칙 수준 인용, 판례 번호 = [미검증]"의 구분이 허용되므로, 조문 문언에 대한 확정 단언(금지 대상)과는 구별된다.

**STEP V·STEPVSC의 선언 정합성**: STEP V는 "점검 결과: 모순 3건 발견"으로 **위반을 인정**하였고 "모순 없음"으로 허위 선언하지 않았다 → **[자기 검증 누락] 해당 없음**.

**결론 영향 후보**: 없음 — 정정 대상은 이유 서술의 정지 작업에 국한되고, 관리처분계획 효력 판단은 판례 법리(원칙 수준)에 기초한다. 주문 변경 없음(STEP V도 "결론: 유지").
