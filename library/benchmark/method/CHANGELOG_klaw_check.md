# K-Law-Check 검수 SP — 갱신 기록 (CHANGELOG)

K-Law-Check는 K-Law가 작성한 가상 판결문을 **별도 API 세션**(가능하면 별도 모델)에서
사후 검수하는 독립 시스템 프롬프트다. 설계 대전제는 "이 판결이 맞는지 판단하라"는 열린
재판단을 시키지 않고, 기계적으로 검증 가능한 작업(제공된 원본 자료와의 텍스트 대조,
빠짐없는 항목 열거)으로 범위를 좁히는 것이다 — 그래야 1차 생성 모델과 같은 지식 분포·
같은 맹점을 공유하는 에코 챔버를 피할 수 있다.

**버전 축이 두 개임에 주의**: 파일명(`klaw_check_v[본체버전].md`)은 이 SP가 **어느 K-Law
본체 버전까지 검토·반영했는지**를 나타내고, 아래 표의 "SP 개정"(`v1.0`, `v1.1`, …)은 **이
SP 자신의 내용이 몇 번 바뀌었는지**를 독립적으로 추적한다. 본체가 새 버전으로 올라가도
이 SP가 그 새 기제를 아직 검토·반영하지 않았다면 파일명을 올리지 않는다 — 반영했을
때만 git mv한다.

최신순으로 기록한다.

**파일**: [`klaw_check_v17_2.md`](klaw_check_v17_2.md) (이전 파일명 `klaw_check_v17_1.md`에서 변경)

**신설**: **M-7** — 0-α 순수성·방향성 기본값·일반화 대상 고정 대조. 본체 v17.2의 세 장치
(P5 STEP 0-α 순수성 격리, P6 강제규칙 3-1 (c-3)·(c-3-1) 상식 기본값 전환, P7 공리 B-1
①-1 일반화 대상 고정)가 **실제로 수행됐는지**를 판결문의 자기 점검 선언과 본문을
대조해 독립 세션에서 재확인한다.

- P5 대조: `[0-α 순수성 자기 점검]` 출력 유무, "위반 없음" 선언 시 실제 금지어 등장
  여부 재대조 → **[P5 자기 점검 누락]** / **[P5 위반 미탐지]**
- P6 대조: `[강제규칙 3-1 발동 여부]`와 0-α·법리 방향 문구의 실제 일치 여부 재대조,
  (c-3)·(c-3-1) 발동 시 ①②③ 중 하나가 실제로 기재됐는지 확인 → **[P6 대조 오류]** /
  **[P6 미이행]**
- P7 대조: 중단판정 사유 ①(일반화 심사) 라운드마다 `[일반화 대상 원문 보존 확인]`
  출력 유무, "예" 선언 시 직전 라운드 논거 원문과 일반화 심사 대상 서술을 나란히
  대조 → **[P7 자기 점검 누락]** / **[P7 보존 확인 불일치]**

세 하위 대조 모두 텍스트·선언 대조 전용이며, (c-3)의 정책적 근거가 **내용상** 타당한지는
판정하지 않는다(사람의 채점에 위임). 증거 사건: 616249(P5), 614333(P7).

  이 SP 파일명이 나타내는 대응 버전을 비교해 격차가 있으면 경고를 출력한다(내용을
  대신 갱신하지는 않는다).
