## M-2 특별법·일반법 우선순위

**검토 영역**: ① 출입국·체류 관리(출국금지 및 통지유예 = 행정처분), ② 국가배상(공무원의 위법한 직무행위), ③ 형사수사(수사 목적 요청 = 배경 사실), ④ 여행계약(취소수수료 = 손해 항목)

**확인한 특별법 후보** (영역별 구체 법률명)
- **① 영역**: 출입국관리법(핵심) / 출입국관리법 시행령·시행규칙 / 행정기본법 / 행정절차법 / 행정소송법
- **② 영역**: 국가배상법(민법 제750조의 특별법) — 제2조·제5조·제8조
- **③ 영역**: 형사소송법 / 검찰청법
- **④ 영역**: **없음** (해당 손해는 인과관계 판단의 대상일 뿐 별도 법률관계로 구성되지 않음)

**판결문 검토 여부**
- ① 출입국관리법 → **검토함**(A-2-0, B-1-1, 판결 이유 2·3항) / 출입국관리법 시행령·시행규칙 → **검토 안 함**(조문 특정 자체를 회피) / 행정기본법 → **조문 미검토**(비례원칙을 '행정법 일반원칙'으로만 보충 적용) / 행정절차법 → **검토 안 함** / 행정소송법 → **검토 안 함**
- ② 국가배상법 → **검토함**(제2조 제1항 적용, 제5조 배제, 제8조 준용 언급) / 민법 제750조 → 특별법 우선 논리로 **배제 검토함**
- ③ 형사소송법·검찰청법 → **검토 안 함**
- ④ 해당 없음

**누락 발견**: **있음 — 다만 경미(결론 변동 개연성 없음)**
1. **행정절차법**: 통지유예(통지 절차의 제한)라는 쟁점 성격상 사전통지·이유제시 규정(제21조·제23조 등)과의 관계 검토가 명시적으로 없다. 다만 출입국관리법이 통지유예를 규율하는 특별법으로 우선 적용되고, 판결은 출입국관리법상 요건 불충족으로 위법성을 인정했으므로 → 결론 변동 개연성 **낮음**.
2. **행정기본법**: 비례원칙·신뢰보호를 명문화한 조문이 검토되지 않고 '일반원칙'으로만 서술됨 → 동일 원칙이 적용되어 결론 변동 개연성 **없음**.
3. **출입국관리법 시행령·시행규칙**: 조문 특정을 회피한 결과 검토 대상에서 빠짐 → 결론 변동 개연성 **없음**.
- (③ 형사수사·④ 여행계약 영역은 국가배상 청구의 위법성·손해 판단에 직접 영향이 없어 실질 누락으로 보지 않음.)

**뭉뚱그린 확인 문구 사용 여부**: 판결문은 "특별법 검토 완료"·"관련 법령 모두 검토" 류의 공허한 확인 문구를 쓰지 않고, 국가배상법·출입국관리법·민법 제750조를 **구체 법률명으로 열거**하였다 → M-2 미이행 아님.

## M-3 프레임 대체 대조 (B-4-δ 블록 존재 — 수행)

**B-4-δ 블록 존재 여부**: **존재함** (STEP B에 `[B-4-δ: 프레임 대체 정당화]` 블록 있음)

**개요상 당사자 프레임**
- **원고**: ① 출국금지·연장·재연장결정이 출입국관리법상 사유 없이 이루어져 재량권 일탈·남용, ② 각 결정의 통지유예가 법정 사유('중대하고 명백한 장애') 없이 이루어져 위법, ③ 담당공무원의 고의·과실 → 피고(대한민국)의 국가배상법상 손해배상(위자료 3천만 원 + 취소수수료 855,000원).
- **피고**: 출국금지·연장·재연장 및 각 통지유예가 출입국관리법상 요건을 충족한 적법 조치 → 책임 부정.

**판결문 채택 여부**: **채택** —
판결문은 원고 프레임 ①(재량권 일탈·남용 → **배척**, 출국금지 적법), ②(통지유예 요건 부존재 → **인용**, 위법), ③(고의·과실 → **인정**)을 그대로 사용하였다. 당사자가 제시하지 않은 별개 법리(예: 신의칙, 무관한 특별법 위반 등)로 사건을 재구성하지 않았으며, 통지유예 위법의 **논증 경로**로 '입증책임 소재'를 원용한 것은 동일 프레임 내의 법리 적용이지 프레임 대체가 아니다(617151류 대체 아님).

**배척 근거 구체성**: **해당 없음 (프레임 대체가 발생하지 않음)** — '제반 사정'·'종합적으로 고려할 때'식 총합 서술로 배척 근거를 갈음한 정황도 없다. 실질적으로 배척이 이루어진 부분(출국금지 자체의 재량권 일탈·남용 주장)도 "사실오인·비례원칙 위반·평등원칙 위반·재량의 불행사 등 유형이 확인되지 않는다"고 **구체적 유형을 열거**하여 배척하였다.

**B-4-δ 블록 누락인데 대체가 발생한 경우**: 해당 없음(블록이 존재하고, 대체 자체가 없음).

## [종합 판정]

**재검토 불요**

- **M-1**: 본 판결 위법성 판단의 핵심 근거 문언("범죄수사에 중대하고 명백한 장애가 생길 우려")은 개요에 원문이 존재하여 **[원문 확인]** → **616497류 법령 문언 환각은 발견되지 않음.** [출처 없음] 1건(국가배상법 제2조 제1항 재현 문언)은 경계 사안이며, 그 논증을 제거해도 결론이 변동하지 않는다.
- **M-2**: 핵심 특별법(국가배상법·출입국관리법)은 구체적으로 검토되었고, 판결문은 공허한 확인 문구 없이 법률명을 열거하였다. 행정절차법·행정기본법·시행령 관련 구체 조문 검토가 명시적으로 이루어지지 않았으나 **결론 변동 개연성은 낮다.**
- **M-3**: **프레임 대체가 발생하지 않았고**(당사자 프레임 그대로 채택), B-4-δ 블록도 적절히 기재되어 있다 → 617151류 결함 없음.

※ 참고: M-1 [출처 없음] 1건 및 M-2 경미 누락은 **결론 무효 소지에 해당하지 않는다.** 위 두 모듈의 판정상 재검토를 요할 중대한 결함은 식별되지 않았다.
