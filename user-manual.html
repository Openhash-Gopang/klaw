K-Law 사용자 매뉴얼

처음 쓰시는 분은 초급부터, 어느 정도 써보신 분은 중급·고급 탭을 바로 봐주세요.

1 K-Law가 뭔가요

Claude·Gemini·DeepSeek 같은 AI 모델은 제조사가 다른 자동차이고, K-Law는 내비게이션입니다. 차종이 달라도 같은 내비게이션을 켜면 같은 길을 따라가는 것처럼, K-Law는 어떤 AI를 쓰든 "이 사건이 대법원까지 가면 어떤 판결이 나올까"라는 같은 목적지로 안내합니다.

사건의 사실관계를 입력하면, K-Law 방법론에 따라 AI가 단계별로 분석해 가상의 판결문을 만들어줍니다. 실제 법적 효력은 없는 시뮬레이션입니다.

2 로그인 한 번이면 무료로 시작

API Key를 따로 발급받지 않아도 됩니다. hondi.net 전화번호 인증만 하면 DeepSeek 모델을 무료로 쓸 수 있습니다(사용량만큼 GDC가 차감됩니다). 화면 우측 상단에 "hondi 인증됨"이 뜨면 준비 완료입니다.

본인이 발급받은 Claude·Gemini·Groq API Key가 있다면 그걸 입력해서 써도 됩니다 — 이 경우 K-Law 서버를 거치지 않고 브라우저에서 바로 해당 AI사에 요청합니다.

3 "사건의 개요" 작성 요령

당사자, 사실관계, 처분·계약 경위, 양측 주장을 최대한 구체적으로 적어주세요. 정보가 부족하면 K-Law가 추측해서 채우기 때문에 결과 품질이 크게 떨어집니다.

부족한 입력 돈 빌려줬는데 안 갚아서 소송 걸었어요.
좋은 입력 원고는 피고에게 2024년 3월 3,000만원을 대여하였으나 피고가 변제기 이후에도 변제하지 않고 있습니다. 피고는 해당 금액이 증여라고 주장합니다.
팁 — 페이지 안의 "시뮬레이션 절차와 방법" 섹션을 펼쳐보면, 실제 판례를 가져와 입력하는 구체적인 방법과 예시 페이지 링크가 있습니다.

4 "분석 시작"을 누르면 벌어지는 일

  1. K-Law가 사건을 분석해 심급·사건분류·쟁점을 정리합니다(사건의 개요, 원고/피고 주장 등).
  2. 정보가 부족하면 추가 질문을 하고, 답변하면 이어서 진행합니다. 충분하면 바로 다음 단계로 넘어갑니다.
  3. STEP 0 → A → B → C 순서로 가상 판결문이 순차적으로 생성됩니다. 화면에 진행 상황이 실시간으로 표시됩니다.

5 결과 읽는 법

  • 법리/사실/종합 확신도 — K-Law 스스로 이 판단에 얼마나 확신하는지(10점 만점).
  • 사건 복잡도 — 사건이 복잡할수록 더 신중한 AI 모델로 자동 전환되어 처리됩니다.
  • 일치도 예상 — K-Law 자체 테스트 기준, 이 정도 복잡도의 사건에서 실제 대법원 판결과 얼마나 일치하는 경향이 있었는지의 추정치입니다. 이번 사건이 실제로 맞았다는 뜻은 아닙니다.
  • 결론 유형 — 확정적 / 조건부 / 판단유보 중 하나. 정보가 부족하면 K-Law가 억지로 결론을 내지 않고 "판단유보"로 표시할 수 있습니다.

1 다른 AI 모델 선택하기

화면 상단의 AI 모델 카드에서 Claude·Gemini·Groq를 선택할 수 있습니다. 단, 이 셋은 K-Law가 자체 서버를 운영하지 않으므로, 해당 회사에서 직접 발급받은 API Key를 입력해야 합니다. 입력한 키는 이 브라우저에만 저장되고 K-Law 서버로는 전송되지 않습니다.

모델마다 법리 해석 성향이 조금씩 다르니, 같은 사건을 여러 모델로 돌려서 비교해보는 것도 좋은 검증 방법입니다.

2 실제 판례로 검증해보기

"시뮬레이션 절차와 방법" 섹션의 안내를 따라가면 됩니다:

  1. 대법원 종합법률정보 등에서 되도록 최신 판례를 하나 고릅니다.
  2. 실제 판결문 작성에 쓸 AI와는 다른 AI를 이용해, "판결 결과를 암시하는 내용은 빼고 사실관계만" 추출합니다.
  3. 추출한 내용을 "사건의 개요"에 붙여넣고 분석을 시작합니다.
왜 다른 AI를 써야 하나요 — 같은 모델이 그 판례를 이미 학습했다면, 사실관계를 추출하는 과정에서 결론이 은연중에 반영되어 검증의 의미가 퇴색될 수 있습니다.

3 원심 판결문까지 같이 넣기

대법원 판결문 하단에는 보통 원심(고등법원 등) 판결문 링크가 있습니다. 그 전문까지 함께 입력에 추가하면 더 자세한 사건 개요를 만들 수 있고, 원심과 대법원 판단이 어떻게 달라졌는지도 비교해볼 수 있습니다.

4 이력 페이지 활용하기

사이드바의 "판결 이력"에서 지금까지 생성한 모든 시뮬레이션을 확인할 수 있습니다. 기본적으로 본인만 볼 수 있고, 각 행의 토글 스위치로 언제든 공개/비공개를 바꿀 수 있습니다. 공개로 전환하면 "공개 게시판"에도 노출됩니다(작성자는 익명으로 표시).

행을 클릭하면 판결문 전문과 항목별 평가 점수를 다시 열람할 수 있습니다.

5 "일치도 평가"로 직접 확인하기

"사건의 개요" 바로 아래 있는 "일치도 평가" 칸에 실제 대법원 판결문 전문을 붙여넣고 "일치도 평가 시작"을 누르면, 방금 생성된 K-Law 가상 판결문과 비교해 "일치도 평가 기준" 방법론에 따른 항목별 점수와 보고서를 볼 수 있습니다. 추정치가 아니라 이번 사건에 대한 실제 비교 결과입니다.

1 방법론 원문 직접 검증하기

페이지 상단 우측의 "방법론 원문" · "출력형식" · "일치도 기준" 버튼으로 K-Law가 실제로 사용하는 원문 문서를 내려받을 수 있습니다. 본인이 쓰는 AI 모델에 이 문서를 직접 넣어 검증해보고 싶을 때 활용하세요.

이 문서들은 저장소에 새 버전이 올라오면 사이트가 자동으로 최신 버전을 반영합니다 — 특정 버전에 고정되어 있지 않습니다.

2 복잡한 사건은 왜 더 오래 걸리나요

당사자가 많거나 입력이 긴 사건은 K-Law가 자동으로 더 신중한(추론 능력이 높은) 모델 티어로 전환합니다. 이 티어는 답변을 쓰기 전에 내부적으로 "생각하는" 과정을 거치는데, 이 사고 과정도 하나의 토큰 예산을 함께 사용합니다. 그래서 복잡한 사건일수록 체감 시간이 길어지고, 드물게는 사고 과정에 예산을 다 쓰고 답변을 못 받는 경우도 있습니다(아래 3번 참조).

3 응답이 잘리거나 비어 있을 때

K-Law는 두 겹의 안전장치를 두고 있습니다:

  • 가벼운 모델의 응답이 토큰 한도로 잘리면, 더 신중한 모델로 자동 전환해 한 번 재시도합니다.
  • 그래도 응답이 완전히 비어 있으면, 훨씬 큰 예산으로 한 번 더 자동 재시도합니다.

두 번 다 실패하면 "다시 시도" 버튼과 함께 명확한 오류 메시지가 표시됩니다 — 이 경우 사건 개요를 좀 더 간결하게 줄여서 다시 입력해보시는 것도 방법입니다.

4 공개 게시판에 올리기 전에

이력을 "공개"로 전환하면 작성자는 익명(예: "이용자-a3f9")으로 표시되지만, 입력하신 사건 개요와 생성된 판결문 전문은 그대로 공개됩니다. 실제 사건의 민감한 정보(당사자 실명, 특정 가능한 세부사항 등)를 입력하셨다면 공개 여부를 신중히 결정해주세요. 비공개로 되돌리는 것도 언제든 가능합니다.

5 K-Law Ensemble(v20.0)과의 차이

현재 이 사이트는 K-Law v15.1을 적용하고 있습니다. 최신 버전인 v20.0(Ensemble)은 서로 다른 제조사의 AI 모델 셋 이상이 각각 피고·원고·판결 역할을 맡아 경쟁·토의를 거쳐 판결문을 만들어, 단일 모델보다 일치도가 더 높습니다. 다만 건당 API 비용이 상당히 커서(약 3,000원) 이 데모 사이트에는 포함되어 있지 않습니다.
