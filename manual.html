K-Law 사용자 매뉴얼초안

K-Law 첫 화면에는 버튼이 다섯 개 있습니다. 이 매뉴얼은 버튼마다 무엇을 하는 곳인지, 왜 만들었는지, 어떻게 쓰는지 설명합니다.

먼저 알아 두세요. K-Law가 만드는 판결문은 AI가 쓴 참고용 가상 판결문입니다. 실제 법원의 판단과 다를 수 있고, 법적 효력이 없으며, 법률 자문이 아닙니다. 소송을 진행하거나 준비 중이라면 변호사와 상담하세요. 이름, 주민등록번호, 연락처, 주소, 계좌번호는 입력하지 말고 가명이나 익명으로 바꿔 쓰세요. 성능 수치는 모두 자체 실험 결과이며 제3자의 검증을 거치지 않았습니다.

하려는 일에 맞는 줄을 찾아 버튼 이름을 확인하세요.

첫 번째부터 세 번째 버튼의 입력 화면은 같은 방식으로 AI를 고릅니다.

  • 기본 AI(DeepSeek)는 API Key 없이 hondi.net 전화번호 인증으로 쓸 수 있습니다. K-Law 공유 계정을 거치며 사용한 만큼 GDC가 차감됩니다.
  • 복합 AI 모델(성능 테스트 · K-Law v15.1 화면의 탭)은 API Key를 입력하지 않습니다. 사이트가 제공하는 AI를 쓰고, 사용한 만큼 로그인한 계정의 GDC에서 차감됩니다.
  • Claude, Gemini, ChatGPT, Groq 등을 쓰려면 직접 발급받은 API Key를 입력해야 합니다. 제공자별 발급 방법은 무료 API Key 획득 방법 페이지에 정리했습니다. 발급 방법은 그 AI에게 물어보셔도 됩니다.
  • API Key 대신 무료 웹 채팅(ChatGPT, Gemini, Claude 등의 채팅 화면)을 쓸 수도 있습니다. 이 경우 K-Law 방법론, 일치도 평가 방법론, 출력형식 문서를 채팅창에 직접 첨부해야 합니다. 문서와 순서는 웹 채팅으로 이용하기를 보세요.
  • API Key는 K-Law 서버에 저장되지 않고 이 브라우저에만 보관됩니다. 1회용 키를 만들어 쓰고, 다 쓴 뒤에는 반드시 폐기하세요. 공용 PC에서는 사용 후 방문 기록을 지우세요.
  • 입력한 사건 내용은 선택한 AI 제공자에게 전송되어, 해당 AI의 성능 개선에 활용됩니다.
  • 성능 테스트 버튼 두 개는 서로 다른 API Key가 최소 두 개 필요합니다. 이유와 쓰는 법은 각 버튼 설명을 보세요.
여러 AI의 결과를 비교해 보세요. ChatGPT, Gemini, Claude 등 여러 LLM에 같은 사건 개요를 입력하여, 가상 판결문 생성 결과를 비교해 보십시오. 가령, ChatGPT와 Gemini에게 각기 같은 사건의 가상 판결문을 생성하게 하고, Claude에게 두 가상 판결문을 전달하여, 어느 쪽이 더 정확한지(혹은 법리가 우수한지) 평가하게 할 수 있습니다. 무료 API를 획득하는 안내문을 참고하십시오.

용도와 목적

소송 중이거나 소송 전인 내 사건에 대해, 법원이 어떻게 판단할 수 있을지 미리 읽어 보는 곳입니다. 실제 판결이 없으므로 일치도는 평가하지 않습니다.

이럴 때 쓰세요

분쟁의 쟁점을 정리하고 싶을 때, 변호사를 만나기 전에 사건을 이해하고 싶을 때, 판결문을 쉬운 말로 풀어 읽고 싶을 때.

적용 방법론

K-Law v15.1 (해외 LLM)

사용법

  1. AI 모델을 고릅니다. 기본(DeepSeek)은 로그인만 하면 되고, 다른 AI는 API Key를 입력합니다.
  2. "사건의 개요"에 사실관계를 적습니다. 당사자의 관계, 분쟁이 생긴 경과(날짜와 금액), 양측 주장, 가진 증거, 가장 다투고 싶은 쟁점을 빠짐없이 적을수록 좋습니다. 소송 중이면 현재 진행 상황도 적습니다.
  3. 계약서나 문서가 있으면 "파일 첨부"로 넣을 수 있습니다(txt, md, csv, docx, pdf). 파일의 글자가 입력란에 추가되므로 내용을 확인하고 고치세요. 개인정보는 가린 뒤 첨부합니다.
  4. "분석 시작"을 누르면 AI가 쟁점을 정리하고, 필요하면 추가 질문을 합니다. 답하면 가상 판결문이 단계별로 작성되고, 이어서 법률 용어를 쓰지 않은 쉬운 설명이 만들어집니다.
  5. 아래 "가상 판결 작성 결과"에 건마다 일련번호, 날짜, 작성자, 사건 개요, 가상 판결문, 쉬운 설명이 순서대로 쌓입니다. 맨 아래에서 공개 여부를 고릅니다.
  • 공개 여부의 기본값은 비공개입니다. 공개하면 공개 게시판에 올라가므로 개인정보가 없는지 다시 확인하세요.
  • 결과는 로그인한 경우에만 저장됩니다. 로그인하지 않으면 화면에는 보이지만 목록에 남지 않습니다.
  • 사건 개요는 상세할수록 결과가 좋아집니다. 중요한 사실이 빠지면 판결문의 품질이 크게 떨어집니다.

최신 대법원 판례로 K-Law의 가상 판결문을 만들고, 실제 판결문과 비교해 일치도를 평가합니다.

K-Law의 성능이 궁금할 때, 연구나 검증을 위해 판례 한 건으로 재현해 보고 싶을 때.

적용 방법론

K-Law v15.1 (해외 LLM)

화면의 탭

이 화면 위쪽에는 탭이 네 개 있습니다.

탭무엇을 하나요
단일 AI 모델DeepSeek, Claude, Gemini 등 하나의 LLM을 골라 가상 판결문을 만듭니다. 복합 AI 모델보다 비용이 저렴합니다. 맨 위의 "LLM 선택" 버튼으로 AI를 고릅니다.
복합 AI 모델둘 이상의 AI가 같은 사건의 가상 판결문을 각각 쓰고, 품질을 평가한 뒤, 최종 판결문을 낼 모델을 고릅니다. 아래 "복합 AI 모델 사용법"을 보세요.
나비 AI 준비 중Navi AI는 A.X 4.0을 대법원 가상 판결문 시뮬레이션에 특화해 Fine-tuning한 모델입니다. 아직 이용할 수 없으며, "분석 시작"을 눌러도 준비 중이라는 안내만 나옵니다. LLM 선택 메뉴는 없고 나머지 화면은 단일 AI 모델과 같습니다.
이력내가 만든 가상 판결문의 목록(생성 시각, 제목, 공개 여부)입니다. 줄을 누르면 판결문 전문을 볼 수 있고, 공개 스위치로 게시판 공개 여부를 정합니다. 이 목록에는 일치도를 표시하지 않습니다.
준비물(단일 AI 모델 탭): API Key 2개 이상. 하나는 사건 개요 작성, 쉬운 설명, 일치도 평가(키 A)에, 다른 하나는 가상 판결문 생성(키 B)에 씁니다. 가능하면 서로 다른 AI 제공자의 키를 쓰세요. 하나의 키로 사건 개요 작성과 가상 판결문 작성을 모두 하면, AI가 이미 정답을 알고 판결문을 쓰게 되어 데이터가 오염됩니다.

사용법 (단일 AI 모델 탭)

  1. 대법원 종합법률정보에서 되도록 최신 판례를 한 건 고릅니다. AI가 이미 학습한 판례는 시험의 의미가 떨어집니다.
  2. 키 A의 AI로 그 판례에서 사실관계만 뽑아 사건 개요를 만듭니다. 법원의 판단, 결론, 주문은 빼야 합니다.
  3. 뽑은 사실관계를 "사건의 개요"에 붙여 넣습니다. AI 모델을 키 B의 AI로 바꾸고(맨 위 "LLM 선택" 버튼과 모델 목록) 키 B를 입력한 뒤 "분석 시작"을 눌러 가상 판결문을 만듭니다.
  4. 판결문이 끝나면 AI 모델을 다시 키 A의 AI로 바꾸고, "일치도 평가" 칸에 실제 대법원 판결문 전문을 붙여 넣은 뒤 "일치도 평가 시작"을 누릅니다. 평가 보고서가 만들어집니다.

복합 AI 모델 사용법

같은 사건을 여러 AI에게 맡겨 서로 비교하고, 가장 나은 판결문을 고르고 싶을 때 씁니다. API Key는 필요 없습니다.

  1. "복합 AI 모델" 탭을 열고 "사건의 개요"에 사실관계를 적습니다. 이 탭은 쟁점 분석과 추가 질문 없이 입력한 개요만으로 판결문을 쓰며, 심급은 정하지 않습니다.
  2. 판결문을 쓸 AI 모델을 2개 이상 고릅니다. 지금은 DeepSeek Pro와 DeepSeek Flash만 고를 수 있고, Claude, Gemini, ChatGPT, Groq는 "서버 준비 중"으로 표시됩니다.
  3. "복합 판결 시작"을 누르면 호출 횟수와 GDC 차감을 알리는 확인창이 뜹니다. 모델마다 STEP 0부터 C까지 같은 순서로 판결문을 쓰며, 모델별 진행 상태가 표시됩니다.
  4. 판결문이 끝나면 평가 모델 하나가 판결문을 어느 모델이 썼는지 가린 채 5개 기준(사실관계 반영 25점, 쟁점·법리 논증 30점, 주문·이유 일관성 20점, 형식·완결성 15점, 근거 신뢰성 10점)으로 채점합니다.
  5. 총점 1위 모델이 미리 선택됩니다. 판결문을 읽어 보고 다른 모델로 바꿀 수 있습니다. "이 모델의 판결문을 최종 판결문으로 확정"을 누르면 그 모델이 쓴 판결문이 최종 판결문이 되고, 이력에 저장됩니다. "판결문 저장"으로 내려받을 수도 있습니다.
  • 최종 판결문은 선택한 모델이 쓴 판결문을 그대로 채택한 것입니다. 여러 판결문을 합치거나 다시 쓰지 않습니다.
  • 평가 점수는 판결문의 품질을 평가 모델이 매긴 것이며, 실제 판결과의 일치도가 아닙니다. 평가 모델도 틀릴 수 있고, 지금은 평가 모델과 작성 모델이 같은 계열이라 자기 계열의 판결문을 유리하게 평가할 수 있습니다.
  • 비용은 모델 수에 비례해 늘어납니다. 모델이 N개이면 판결문 작성 4N회와 평가 1회를 호출합니다. 진행 중에 페이지를 닫거나 새로고침하면 중단됩니다.
  • 복합 AI 모델 탭에는 "일치도 평가" 칸이 없습니다. 실제 판결문과 비교하려면 단일 AI 모델 탭을 쓰세요.
  • 여기서 나오는 수치는 선별한 판례에서 잰 자체 실험 결과이며, 모든 사건에 그대로 적용되지 않습니다. 자세한 결과와 논문은 K-Law 자료실에 있습니다.
  • 일치도 평가 기준은 자료실의 "일치도 평가 기준" 문서에서 볼 수 있습니다.

용도와 목적

Agon은 1심, 2심, 3심과 헌법재판소로 나뉜 판단을 하나로 합친 가상의 "통합심"과 그 "표준 판결문"을 만드는 것이 목표인 방법론입니다. 이 페이지는 그 성능을 시험하는 곳입니다.

이럴 때 쓰세요

이전 K-Law(v15.1)와 Agon이 어떻게 다른지 직접 비교하고 싶을 때.

적용 방법론

Agon 0.x (시험 단계, 해외 LLM). 정식 Agon 1.0은 2027년 상반기 공개 예정입니다.

준비물: API Key 2개 이상. 하나는 사건 개요 작성, 쉬운 설명, 일치도 평가(키 A)에, 다른 하나는 가상 판결문 생성(키 B)에 씁니다. 가능하면 서로 다른 AI 제공자의 키를 쓰세요. 하나의 키로 사건 개요 작성과 가상 판결문 작성을 모두 하면, AI가 이미 정답을 알고 판결문을 쓰게 되어 데이터가 오염됩니다.

사용법

  1. 입력 화면은 앞의 "성능 테스트 · K-Law v15.1"과 같은 순서입니다. 최신 대법원 판례를 고르고, 키 A의 AI로 사실관계만 뽑아 "사건의 개요"를 만듭니다.
  2. Agon의 사건 개요는 원심 결과를 가린 독립 개요입니다. 당사자, 경위, 청구와 주장만 넣고 1·2·3심의 결론, 법원명, 사건번호는 뺍니다.
  3. 개요를 "사건의 개요"에 넣고 AI 모델을 키 B의 AI로 바꿔 키 B를 입력한 뒤 "분석 시작"을 누릅니다. 원고 청구, 피고 방어, 재반박을 거치는 변증법적 공방과 자기 검증을 거쳐 가상 판결문이 만들어집니다.
  4. AI 모델을 다시 키 A의 AI로 바꾸고 "일치도 평가"에서 실제 판결문과 비교합니다. 평가 기준은 Agon용(법리와 승소 당사자 중심)을 씁니다.
  • 화면 위쪽의 "K-Law와 Agon 비교표 보기"에서 입력 데이터, 판단 방법, 채점 방식의 차이를 볼 수 있습니다. 두 방법론의 일치도는 직접 비교할 수 없습니다.
  • 지금 단계의 결과는 잠정치이며 제3자 검증 전입니다.

사용법

  1. 맨 위의 두 탭에서 Agon(현재 시험)과 이전 K-Law v15 판결 성능 검증(300건 기록)을 고릅니다.
  2. Agon 탭에서 라운드를 고르면 그 라운드가 쓴 방법론, 사건별 실제 판결문, 사건 개요, Agon의 가상 판결문, 법리 일치 여부, 단계별 결과, 방법론을 갱신했는지 보류했는지에 대한 판단 근거를 볼 수 있습니다.
  3. "실험 환경", "날짜별 진행 기록", "방법론 갱신 기록", "검수 SP", "일치도 성적표 다운로드(CSV)"는 눌러서 펼치는 항목입니다.

  • 아직 진행하지 않은 라운드는 표시만 있고 내용이 없습니다. 수치는 진행 중인 잠정치입니다.
  • Agon은 원심 결과를 보지 못하므로 사실인정과 원심 판단의 근거가 없다는 구조적 한계가 있습니다. 같은 페이지의 설명을 함께 읽으세요.

이동 중에 휴대폰으로 사건을 정리할 때, 긴 개요를 직접 쓰기 어려울 때.

알아 둘 점

"AI 모델 설정"은 아직 화면 시안입니다. 선택은 기기에 저장되지만 실제 판결 생성은 K-Law 공유 계정(DeepSeek)이 처리합니다.

사용법

  1. 처음 열면 AI가 인사하며 어떤 일이 있었는지 묻습니다. 사건을 편하게 이야기하듯 입력합니다. 문서가 있으면 첨부할 수 있습니다.
  2. AI가 부족한 사실을 하나씩 되묻습니다. 아는 만큼 답합니다.
  3. 사건 파악에 필요한 정보가 모이면 AI가 "이 내용으로 가상 판결문을 생성할까요?"라고 묻고, 예상 요금을 보여 줍니다. 더 말할 내용이 있으면 버튼을 누르지 말고 계속 입력하세요.
  4. "네, 이 내용으로 생성해 주세요"를 누르면 가상 판결문이 만들어지고, 결과를 새 탭에서 열어 볼 수 있습니다.
  • 하루에 만들 수 있는 판결문 수에 한도가 있고, 남은 횟수가 버튼에 표시됩니다.
  • 베타 기간(2026년 12월 31일까지)에는 정액이 아니라 사용한 만큼 요금이 청구됩니다.
