무료 API Key 획득 방법

K-Law는 자체 AI 키를 제공하지 않습니다. 기본 AI(DeepSeek)를 쓰지 않고 Claude, Gemini, ChatGPT, Groq 등을 쓰려면 직접 API Key를 발급받아 입력해야 합니다. 이 페이지는 제공자별 발급 방법과 비용을 정리한 것입니다.

먼저 알아 두세요. 아래 내용은 2026년 10월 13일에 각 제공자의 공식 문서에서 확인한 것입니다. 요금과 무료 한도는 제공자가 수시로 바꾸므로, 발급 직전에 각 제공자의 발급·요금 페이지에서 다시 확인하세요. 실제로 무료 이용이 확인된 곳은 Google Gemini와 Groq 두 곳입니다. Claude, ChatGPT, DeepSeek은 무료 이용을 안내하는 공식 문서를 확인하지 못했습니다. 이 세 곳은 결제 수단 등록이나 선불 충전을 준비해 두는 편이 안전합니다.

한눈에 보기

제공자무료 이용비용 방식발급 페이지
Google Gemini있음 (일부 모델)무료 등급은 결제 없이 사용. 한도 초과 시 유료 등급 필요aistudio.google.com/apikey
Groq있음 (무료 요금제)모델별 분당·일일 한도가 있음. 상위 요금제는 유료console.groq.com/keys
DeepSeek안내 없음선불 충전 후 토큰 사용량만큼 차감platform.deepseek.com/api_keys
Claude (Anthropic)안내 없음사용량 기반 결제. 신규 조직은 낮은 한도로 시작platform.claude.com/settings/keys
ChatGPT (OpenAI API)안내 없음선불 크레딧 구매(최소 5달러)platform.openai.com/api-keys

ChatGPT 앱이나 Claude 앱의 월 구독과 API는 별개입니다. 구독을 하고 있어도 API Key는 위 페이지에서 따로 발급받고 결제해야 합니다.

Google Gemini무료 가능

  1. aistudio.google.com/apikey에 접속해 Google 계정으로 로그인합니다.
  2. 처음이면 약관에 동의합니다. 기본 프로젝트와 키가 자동으로 만들어질 수 있습니다.
  3. Create API key를 누릅니다.
  4. 만들어진 키를 복사해 K-Law의 API Key 입력란에 붙여 넣고, AI 모델에서 Gemini를 선택합니다.
  • 무료 등급에서는 일부 상위 모델이 제외됩니다. K-Law에서 오류가 나면 모델을 바꿔 보세요.
  • 무료 등급에 입력한 내용은 Google의 제품 개선에 사용됩니다(공식 가격표의 "Used to improve our products: Yes"). 유료 등급은 사용하지 않는다고 적혀 있습니다. 무료 키로 사건을 입력할 때는 개인정보를 반드시 가리세요.
  • 공식 안내는 키를 비밀번호처럼 다루라고 합니다. 남에게 보이지 않게 하세요.

Groq무료 가능

  1. console.groq.com/keys에 접속해 가입하고 로그인합니다.
  2. Create API Key를 누르고 이름을 붙입니다.
  3. 키는 만들어진 직후 화면에서 복사해 두세요. 나중에 다시 볼 수 없을 수 있습니다.
  4. K-Law의 API Key 입력란에 붙여 넣고, AI 모델에서 Groq를 선택합니다.
  • 무료 요금제에는 모델별로 분당·일일 요청 수와 토큰 한도가 있습니다. 긴 판결문을 만드는 도중 "한도 초과" 오류가 날 수 있습니다. 그러면 잠시 뒤에 다시 시도하세요.
  • 정확한 한도는 로그인 후 계정 설정의 Limits 페이지에서 확인할 수 있습니다.

DeepSeek무료 확인 안 됨

  1. platform.deepseek.com에 가입하고 로그인합니다.
  2. 잔액을 충전합니다. 공식 문서는 실제 사용량에 맞춰 충전하라고 안내합니다.
  3. API keys 페이지에서 새 키를 만들고 복사합니다.
  4. K-Law의 API Key 입력란에 붙여 넣고, AI 모델에서 DeepSeek을 선택합니다.
  • 요금은 입력·출력 토큰 수에 따라 매겨집니다. 공식 가격표 기준으로 Flash 모델의 출력은 100만 토큰당 0.6~1.2달러입니다(한가한 시간대가 절반 가격).
  • 신규 계정에 지급되는 크레딧이 있을 수 있지만 공식 문서에서 그 조건을 확인하지 못했습니다. 지급 여부를 기대하지 마세요.
  • K-Law의 기본 AI는 DeepSeek이며, 키 없이 hondi.net 전화번호 인증으로도 쓸 수 있습니다(사용한 만큼 GDC 차감). 직접 키가 필요한 경우는 주로 두 번째 키를 마련할 때입니다.

Claude (Anthropic)무료 확인 안 됨

  1. platform.claude.com(Anthropic Console)에 가입하고 로그인합니다.
  2. Billing 페이지에서 결제를 설정합니다.
  3. Account Settings의 API keys에서 새 키를 만듭니다. 키 유형과 만료일을 정할 수 있습니다.
  4. K-Law의 API Key 입력란에 붙여 넣고, AI 모델에서 Claude를 선택합니다.
  • 무료 이용을 안내하는 공식 문서는 확인하지 못했습니다. 신규 조직은 낮은 한도(Evaluation 등급)로 시작하고, 사용 내역이 쌓이면 한도가 자동으로 올라갑니다.
  • Billing 페이지에서 월 사용 한도를 확인하세요. 사용 내역과 한도는 그곳에서 볼 수 있습니다.

ChatGPT (OpenAI API)무료 확인 안 됨

  1. platform.openai.com에 가입하고 로그인합니다.
  2. Billing 페이지에서 크레딧을 구매합니다. 최소 구매액은 5달러입니다.
  3. API keys 페이지에서 새 시크릿 키를 만들고 복사합니다.
  4. K-Law의 API Key 입력란에 붙여 넣고, AI 모델에서 ChatGPT를 선택합니다.
  • 계정에 무료 크레딧이 있으면 구매한 크레딧보다 먼저 사용됩니다. 다만 무료 크레딧이 지급되는 조건은 공식 문서에서 확인하지 못했습니다.

성능 테스트용 키 두 개 마련하기

성능 테스트 버튼 두 개는 서로 다른 API Key가 최소 두 개 필요합니다. 키 A는 사건 개요·쉬운 설명·일치도 평가에, 키 B는 가상 판결문 생성에 씁니다. 같은 키로 사건 개요와 판결문을 모두 만들면 AI가 이미 정답을 알고 판결문을 쓰게 되어 시험 결과가 오염됩니다.

무료로 두 개를 마련하려면 Gemini와 Groq에서 각각 한 개씩 발급받는 방법이 있습니다. 두 곳 모두 무료 이용이 확인된 제공자입니다.

키를 안전하게 쓰는 법

  • K-Law는 API Key를 서버에 저장하지 않고 이 브라우저에만 보관합니다. 그래도 1회용 키를 만들어 쓰고, 다 쓴 뒤에는 발급 페이지에서 키를 삭제(폐기)하세요.
  • 공용 PC에서는 사용 후 방문 기록과 사이트 데이터를 지우세요.
  • 키가 남에게 노출됐다면 즉시 삭제하고 새로 발급받으세요.
  • 유료 제공자는 월 사용 한도를 걸어 두세요.
  • 입력한 사건 내용은 선택한 AI 제공자에게 전송됩니다. 실명·주민등록번호·연락처·주소·계좌번호 등은 가명이나 익명으로 바꿔 입력하세요.
