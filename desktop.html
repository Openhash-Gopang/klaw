K-Law는 어떻게 동작하나요

Claude·Gemini·DeepSeek 등은 제조사가 다른 자동차이고, K-Law는 내비게이션입니다. 차종이 달라도 같은 내비게이션을 켜면 같은 길을 따라 주행하는 것처럼, K-Law는 어떤 LLM을 타든 "대법원 예상 판결문"이라는 같은 목적지로 안내합니다.

시뮬레이션을 실행하려면 각자 탑승할 자동차(LLM)의 API Key를 입력해야 합니다 — K-Law는 자체 LLM 서버를 운영하지 않습니다. 입력하신 키는 이 브라우저에만(localStorage) 저장되어 다음 방문 시 자동으로 채워지며, K-Law 서버로는 전송되지 않습니다. 공용 PC라면 브라우저 방문 기록 삭제 시 함께 삭제됩니다.

💰 비용 대비 효용은 DeepSeek이 압도적입니다.
K-Law Ensemble은 단일 모델이 아니라, 다수의 LLM들 간의 경쟁과 토의를 거쳐 도출된 판결문입니다. 서로 다른 모델이 독립적으로 판단한 뒤 의견이 갈리는 지점을 다시 토론시켜, 단일 모델보다 높은 일치도(약 95%)를 보입니다.
📊 한국 사회에서 발생하는 모든 사건이 대법원까지 진행한다고 가정할 경우, K-Law의 가상 판결문과 대법원 실제 판결문 간의 일치도는 99.9% 이상으로 추정됩니다. (근거: 논문 초고 참조 — 위 표는 이미 대법원까지 도달한 쟁점 사건만을 대상으로 한 수치입니다.)
⚠️ 같은 사건에 대해 K-Law Ensemble의 가상 판결문과 대법원의 실제 판결문이 모순되거나 반대되는 경우, 어느 쪽의 법리가 헌법과 법률에 더 부합하는지는 K-Law가 판단할 수 없습니다. 본 시뮬레이션은 참고용 예측이며, 실제 법적 효력이나 구속력을 갖지 않습니다.
🔒 판결 시뮬레이터는 LLM의 웹 검색 기능을 의도적으로 차단하였습니다. 웹 검색을 허용하면 일치도가 상승하겠지만, 실제 사건 정보를 획득할 수 있게 되어 순수한 법리 추론 능력을 검증하려는 목적이 훼손될 수 있습니다.
⚠️ 주의 — 입력 완전성에 대하여
본 시뮬레이터는 K-Law 방법론 원문 · 일치도 평가 기준 · 가상판결 출력형식 문서를 매 STEP마다 LLM에 전달합니다. 다만 LLM마다 컨텍스트 윈도우 크기가 다르고, 모델에 따라 긴 입력을 받아도 끝까지 반영하지 못하거나 일부를 누락할 수 있습니다. 확실하고 완전한 입력을 원하시면:
  • 충분히 큰 컨텍스트 윈도우를 지원하는 모델을 권장합니다.
  • 결과에 [STEP-0-COMPLETE] 등 완료 태그가 모두 출력됐는지 확인하세요 — 누락 시 입력이 온전히 처리되지 않았을 가능성이 있습니다.
  • 아래에서 원문을 직접 내려받아 사용 중인 LLM에 직접 검증해보실 수 있습니다.

무료 API Key 발급 방법

K-Law는 자체 LLM 서버를 운영하지 않습니다. 아래 제공자 중 하나를 선택해 무료(또는 평가용) API Key를 발급받아 입력하면 바로 이용할 수 있습니다.

🟦 Google Gemini

Google AI Studio에서 가입 후 무료 등급(Free Tier)으로 API Key를 즉시 발급받을 수 있습니다.

aistudio.google.com/app/apikey ↗
🟧 DeepSeek

DeepSeek 플랫폼에 가입 후 신규 계정에 제공되는 무료 크레딧으로 API Key를 발급받을 수 있습니다.

platform.deepseek.com/api_keys ↗
🟪 Anthropic Claude

Anthropic Console에서 가입 후 API Key를 발급받을 수 있습니다. 신규 계정에는 평가용 크레딧이 제공됩니다.

console.anthropic.com/settings/keys ↗
🟩 Groq

Groq Cloud는 Llama 등 오픈소스 모델을 매우 빠른 속도로 무료 제공합니다. 가입 후 즉시 API Key 발급이 가능합니다.

console.groq.com/keys ↗
⬜ 기타 무료/저비용 제공자

OpenRouter는 여러 모델의 무료(:free) 엔드포인트를 통합 제공하며, Cloudflare Workers AI도 일정량을 무료로 제공합니다.

openrouter.ai/keys ↗ Cloudflare Workers AI ↗

⚠️ 발급받은 API Key는 본인의 브라우저에만(localStorage) 보관되며 K-Law 서버로 전송되거나 저장되지 않습니다. 각 제공자의 요금 정책 및 무료 한도는 변경될 수 있으니 발급 페이지에서 최신 정보를 확인하세요.
